How To Get Google Chrome Experimental Features In The Toolbar

Google tests all of the features it releases for its Chrome browser before they are launched publicly and users who are interested can play around with them before they are released. There's more than one way for users to test experimental Chrome features before the final release but the latest method offered is the quickest and easiest. Chrome Labs browser experiments can now be accessed directly from the toolbar, but only in a special version of the browser.

✕ Remove Ads

Google Chrome is the most popular web browser, having initially surpassed the now discontinued Internet Explorer on its way to the top. In fact, Google has over 60 percent of the global market, enjoying a commanding lead over every other browser used for desktop and laptop computers. The incredible success of the browser led to Google’s development of devices that use the same name such as its Chromebook laptop, which runs ChromeOS, and Chromecast, a media streaming device that connects to a television to allow ‘casting’ from a computer or mobile device to the TV.

Google Chrome now allows quick and easy access to its Chrome Labs experiments directly from the toolbar, as noted by GHacks. To enable the extension requires the use of a variation of Google’s browser called Canary. Canary is like the alpha version of Chrome. Google also makes an intermediate version available called Chrome Beta. However, the Chrome Labs toolbar icon is only available for Canary, which is a separate app to download and install.

✕ Remove Ads

Installing Canary & Enabling Labs

After downloading and installing Google Chrome Canary, users can enable the Chrome Labs toolbar icon. Many of the special features that are available for testing through Canary must be enabled first by using the flags page. The beaker icon that represents Chrome Labs experiments uses this method. In the address bar, the user can type ‘chrome://flags’ to access this page, then scroll down or search the page to find ‘chrome-labs’ and set it to ‘Enabled.’ Restarting Canary should result in the beaker icon appearing next to the address bar.

✕ Remove Ads

After installing Google’s Canary browser and enabling Chrome Labs through the flags page, the user has easy access to experiments that being tested for Chrome. These can be enabled and disabled at any time, though most require restarting the browser to see the effect. This is a much more inviting way to try out these browser features and may lead to a greater number of participants for each experiment. It should be noted that the most reliable version of Google’s browser is Chrome and anyone testing new features on Chrome Beta or Chrome Canary should be prepared for more frequent issues with websites and even the occasional crash.
