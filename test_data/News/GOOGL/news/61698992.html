I Squared Capital收购两家公司，为其亚洲数字基础设施平台增加云迁移和托管服务专长

December 10, 2020 10:06 PM Eastern Standard Time

新加坡--(BUSINESS WIRE)--(美国商业资讯)--I Squared Capital已通过其ISQ Global Infrastructure Fund II，收购且合并了两家总部位于新加坡的云迁移服务公司Infofabrica Holdings Pte Ltd和Cloud Kinetics Tech Pte Ltd。合并后的公司具备所有主要公共云运营商的能力，有望成为东南亚和印度领先的云迁移和托管服务提供商。这些投资是新的亚洲数字基础设施平台的一部分，将使I Squared Capital的数字基础设施公司能够为其客户提供全面的云解决方案。该云平台将拥有300多名专业人员，他们拥有丰富的云基础设施、数据、分析、应用现代化和云管理经验，以及广泛的云认证能力。

I Squared Capital执行合伙人Gautam Bhandari表示：“数据和计算的未来驱动力将来自于企业对内部基础设施、主机托管和云服务的精心组合而实施的混合云解决方案。提供无缝、高效的混合云迁移可缓解采用云的关键瓶颈，尤其是在亚太地区。Infofabrica和Cloud Kinetics的合并将为我们的客户带来一个强大的云迁移解决方案提供商。这些收购让我们在数字基础设施领域的全球投资和承诺额超过了26亿美元，并且还在不断增长。”

云迁移涉及由认证专家执行的专门功能和技术，以使企业能够无缝迁移到云并在云端运营。IDC预测，东南亚的云计算市场到2025年将达到400亿美元，这也突显了云计算在我们日常生活中的重要性。该平台的共同创始者和现任领导人为曾在Google Cloud、Cisco、Hewlett Packard Enterprise和Dell担任高级领导职务的技术高管Haji Munshi，以及Quvat Capital前创始合伙人、曾在美林银行和德意志银行任职的东南亚投资银行家Tameem Ebrahim。

InfoFabrica和Cloud Kinetics集团首席执行官Haji Munshi表示：“在经历Covid-19大流行之后，关于云需求的争论已经结束。企业可在云端开发和测试新应用程序，扩展在线电子商务服务，也可以运行核心业务工作负载，这一切都是因为公共云提供了稳定的可扩展解决方案。迄今为止，对迁移到云的技术能力的需求远远超过了亚太地区的供应，而合并后的公司将成为云迁移服务的市场领导者。”

IFF董事长Abu Bakar Mohd Nor表示：“我们非常高兴与I Squared Capital合作，他们在亚洲的专长和广度，再加上对电信和数据中心的现有大规模投资，无疑将加速并推动我们更进一步地实现成为该地区顶级云迁移和托管服务提供商的愿景。 InfoFabrica和Cloud Kinetics的互补能力是关键，也是我们成为端到端云专家和简化客户云迁移旅程的战略的一部分。”

关于Infofabrica Holdings (https://www.infofabrica.com/)：InfoFabrica Holdings Pte Ltd成立于2013年，在新加坡、印尼、越南和马来西亚开展业务运营。InfoFabrica是Amazon Web Services、Google Cloud和IBM Cloud的认证云合作伙伴。

关于Cloud Kinetics (https://www.Cloud-kinetics.com/)：Cloud Kinetics Tech Pte Ltd成立于2012年，在新加坡、泰国、印度和美国开展业务运营。Cloud Kinetics是Microsoft Azure、Amazon Web Services和Google Cloud的认证云合作伙伴。

关于I Squared Capital (http://www.isquaredcapital.com/)：I Squared Capital是一家独立的全球基础设施投资管理公司，专注于美洲、欧洲和亚洲的能源、公用事业、数字基础设施、运输和社会基础设施。公司在迈阿密、香港、伦敦、新德里、纽约和新加坡均设有办事处。
